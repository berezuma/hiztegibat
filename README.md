# Hiztegi bat #

Proiektu hau **Gorka Urbizu** musikariaren letretan oinarritutako euskara ikasteko hiztegi bat da. Asmoa da letretan agertzen diren hitz bereziak —jasoak, mailegatuak, dialektalak edo hitz-eraketa erakusteko baliagarriak— bildu eta haien esanahia ematea, jendeak euskara letra horien bidez landu dezan.

Proiektu hau [ZiTAL/bermiotarra](https://github.com/ZiTAL/bermiotarra) proiektuaren kodean oinarrituta dago (GPL 3.0 lizentzia). Eskerrik asko ZiTAL-i bere lana komunitatearentzat eskura jartzeagatik.

Iturriak: Gorka Urbizuren bakarkako *Hasiera bat* (2024) eta **Berri Txarrak** taldearen diskografia osoa (1997–2019), letra guztiak Gorka Urbizurenak. **Letrak ez dira hemen kopiatzen** (egile-eskubideen jabearenak dira): hitz solteak eta aipamen laburrak baino ez dira erabiltzen, beti abestiaren eta diskoaren izenarekin.

## Edukia ##

- `letrak/` — iturrien erreferentziak: `gorka-urbizu-hasiera-bat-2024.txt` eta `berri-txarrak/` (disko eta abesti zerrendak, letra ofizialetarako estekekin; letrak ez dira kopiatzen).
- `berbak/` — hiztegia, letraz letra antolatuta (`a.md` … `z.md`).
- `web/` — web-aplikazioa (eraikitze-prozesua eta bilatzailea), Bermiotarra proiektutik egokitua.

## Hiztegi-sarreren formatua ##

Sarrera bakoitzak honakoak ditu:

- **Hitza** (izenburu gisa); zentzu bat baino gehiago izanez gero, zenbakituta.
- Definizio argia euskaraz.
- Letretako adibidea(k), etzanez, dagokion abestiaren izenarekin.
- Datu-lerro bat: **kategoria** gramatikala · **sinonimoak** · **osaera** edo etimologia, irakasteko baliagarria denean · **erregistroa** (jasoa, ahozkoa, mailegua…).

## Oharra egiletzaz eta lizentziaz ##

Letren testuak Gorka Urbizurenak dira eta hemen aztertze- eta ikaste-helburuarekin baino ez dira erabiltzen. Hiztegi-sarrerak, definizioak eta hizkuntza-iruzkinak lan eratorria dira. Proiektu honetako kodea eta hiztegi-edukia **GPL 3.0** lizentziapean daude; letren eskubideak haien egilearenak dira.
