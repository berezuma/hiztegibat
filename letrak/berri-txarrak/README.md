# Berri Txarrak — diskografia #

Berri Txarrak (1994–2019), Lekunberriko hiru kideko taldea; letra guztiak **Gorka Urbizu**renak.

Hemen disko eta abesti zerrendak baino ez daude, abesti bakoitzaren letra ofizialerako estekarekin. **Letrak ez dira kopiatzen** — egile-eskubideen jabearenak dira. Hiztegirako (`../../berbak/`) hitz solteak eta aipamen laburrak baino ez dira erabiltzen, beti diskoaren eta abestiaren izenarekin.
