# Letrak — iturriak #

Hemen ez dira letren testuak osorik gordetzen (egile-eskubideen jabearenak dira). Iturri eta erreferentzia gisa baino ez daude:

- `gorka-urbizu-hasiera-bat-2024.txt` — Gorka Urbizuren bakarkako *Hasiera bat* (2024) letrak; proiektu honen abiapuntua.
- `berri-txarrak/` — Berri Txarrak taldearen diskografia (Gorka Urbizu letragilea): disko eta abesti zerrendak, letra ofizialetarako estekekin (berritxarrak.net). Letrak ez dira hemen kopiatzen.

Helburua: letra horietatik **hitz solteak** atera eta `../berbak/` hiztegira gehitzea, esanahiarekin eta aipamen laburrekin, euskara ikasteko.
