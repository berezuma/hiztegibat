# MAKULU #

1. Oinez ibiltzeko laguntza-tresna, besapean edo eskuan eusten dena.
2. (Hed.) Norbaiti edo zerbaiti eusten dion bermea.

- Abesti baten izenburua: «Makuluak» — *Haria* (2011)

**Kategoria:** izena · **Sinonimoak:** euskarri, sostengu, bermatoki (2) · **Esamoldeak:** *makulu izan* = norbaiti eustea (ik. *itsuaren eskuaren pareko*, i.md).

# MANTXA #

Orbana, zikinkeria-marka; azalera bat zikintzen edo nabarmentzen duen tanta edo eremua.

- *mantxa gorri bat itsasoan zabaltzen* — «Kolore bat»

**Kategoria:** izena · **Sinonimoak (euskara batuan):** orban, zikinune, lohi-marka · **Erregistroa:** mailegua (gaztelaniazko *mancha*); idatzizko erregistro jasoan *orban* hobesten da.

# MENDEKU #

Norbaitek egin dion kaltearen ordaina; mina jaso ondoren atzera egitea, justizia gisa edo zigorraren ordez.

- *edango dugu gogotik mendekuaren likore garratzetik* — «Lepokoak»

**Kategoria:** izena · **Sinonimoak:** bendekio, ordain (asmo txarrekoa) · **Lotutakoak:** *mendekatu* = mendekua hartu; *mendekugarri* = mendekua merezi duena · **Esamoldeak:** *mendekuaren legea*; *mendekuz beteta*.

# MERKEALDI #

Salgaiak ohi baino prezio txikiagoan saltzen diren denbora-tartea; (hed., gaitzezkoz) gauza edo pertsonak balio baxuan salduriko garaia.

- *bizi garen mende honetako bukaerako / eta hasierako giza merkealdia* — «Izebergaren punta»

**Kategoria:** izena · **Sinonimoak:** beherapen-aldi, errebajak (mailegua) · **Osaera:** *merke* + *-aldi* (denbora-tarte-atzizkia: *udaldi, gerraldi*).

# MESPRETXATU #

Norbait edo zerbait gutxitzat hartu, balio gabekotzat jo, erdeinatu.

- *hala zabaltzen da izurri berri hau: irribarre batez / kanpokoa mespretxatzen aurrerakoi trajea kendu gabe* — «Zuri»

**Kategoria:** aditza · **Sinonimoak:** erdeinatu, gutxietsi, arbuiatu · **Antonimoak:** estimatu, balioetsi · **Lotutakoak:** *mespretxu* = gutxiespena (ik. *erdeinu*, *destaina*).

# MIAZKATU #

Mihiarekin azala edo gainazala ukitu eta likido edo hautsa hartu; (hed., gaitzezkoz) norbaiti atsegin emateko leloki jokatu (lausengu).

- *zertan ari zara / gogoratu nahi ez ditugunen / uzkia miazkatzen?* — «Stereo»

**Kategoria:** aditza · **Sinonimoak:** miztu, milikatu (ik. m.md), lamiztu · **Erregistroa:** ahozkoa; aldaera *milikatu*ren senidea.

# MILIKATU #

Mihiarekin azala kendu edo lehortu; (hed.) zerbaiti aurpegi bigunez heldu, lausenguz tratatu.

- *non aurkitu zure zauriak / milikatuko dituen hura* — «Alegia»

**Kategoria:** aditza · **Sinonimoak:** mihiztatu, lamiztatu, miazkatu (aldaerak) · **Erregistroa:** ahozko hizkera bizia · **Esamoldeak:** *zauriak milikatu* = oinazea kontsolatu edo bere arian luzatu.

# MINBIZI #

Gorputzeko zelulen kontrolik gabeko hazkundeak sortzen duen gaixotasun larria; kantzerra. (Hed.) zabaltzen den okerra.

- *minbizi atsegin bat da zuen irria / heriotz jasangarria* — «Hemen sukaldarien herrian»
- *jendea da euren arazoa / aniztasuna minbizia* — «Onak eta txarrak» (ironia)

**Kategoria:** izena · **Sinonimoak:** kantzer, gaixotasun gaiztoa · **Osaera:** *min* (oinazea, kaltea) + *bizi* (bizirik dagoena) → "bizirik dagoen mina", bere kasa hedatzen den oinazea.

# MINTZATU #

Hitz egin, hizketan aritu. Hitz jasoa eta literarioa.

- *gu eguraldiaz nola halaxe mintzatuko da / neurri berean eguraldia gutaz* — «Spoiler!»
- *zein dira oihuka mintzo direnak?* — «Maravillas» (*mintzo* = mintzatu aditzaren forma trinkoa)

**Kategoria:** aditza · **Sinonimoak:** hitz egin, solastu, jardun (hizketan) · **Lotutakoak:** *mintzaira* = hizkuntza; *mintzaldi* = hitzaldia · **Erregistroa:** jasoa/literarioa · **Oharra:** forma trinkoak ohikoak: *mintzo naiz, mintzo zara, mintzo da*.

# MIRABE #

Norbaiten zerbitzura dagoena, morroia; (hed.) menderakuntza handian dagoena, askatasunik gabea.

- *Gogoan dut orain aspaldiko aholkua: / ez fida herraren mirabe denaz* — «Maravillas»

**Kategoria:** izena · **Sinonimoak:** morroi, esklabo, neskame · **Antonimoak:** nagusi, jabe · **Erregistroa:** jasoa/literarioa.

# MIRARI #

Ohiko legearen kontrako gertakaria, ulertezina edo natur-azalpenik gabea; gauza harrigarria.

- *Ez dago miraririk, badakizu / Bizitzea besterik, badakigu* — «Isiltzen banaiz»

**Kategoria:** izena · **Sinonimoak:** miraku, harritzeko gertakari · **Erregistroa:** mailegua (latinetik *miraculum*) · **Lotutakoak:** *miragarri* = mira eragiten duena; *miretsi* = mirespenez behatu (ik. *miretsi*).

# MIRETSI #

Begi onez eta liluraz behatu, txundituta gelditu; norbait edo zerbait estimuz hartu.

- *jaio nintzen hiria mirestu dudanean / nahiz parkingak dauden orain / gure historiaren sotoetan* — «Pintadek»

**Kategoria:** aditza · **Sinonimoak:** estimatu, txundituta gelditu, txalotu · **Lotutakoak:** *miresgarri* = miretsi merezi duena; *mirespen* = miretsiaren ekintza · **Erregistroa:** jasoa.

# MORTU #

Lehor, antzu, hutsik geratutako lekua; (hed.) bizirik gabe dagoen edo iraindua izan den lurra.

- *auzolotsaren zaflada / itzelezko amorrua / hildakoen hierarkia Gaza mortuan* — «Arren, Darwish»

**Kategoria:** izenondoa/izena · **Sinonimoak:** basamortu, antzu, idor · **Erregistroa:** jasoa (latinezko *mortuum* "hila" zentzu zabalduan); biblia eta literatura jasoan ohikoa.

# MURRU #

Harlanduzko edo adreiluzko horma sendoa, eraikuntza zaharretan ohikoa; (hed.) bizi-zentzuan, gainditzeko zaila den hesia.

- *herrialde aberatsen dominak / pilatuz jasotako murruak / itsututa ez duzue ikusten / handinahi honen ondorioak* — «Pangea»

**Kategoria:** izena · **Sinonimoak:** horma, harresi, esi-handi · **Erregistroa:** jasoa (latinezko *murus*-etik).

# MIN ARINDU #

Norbaiti oinazea edo atsekabea gutxitu, kontsolatu (ik. *arindu*, a.md).

- *zure mina arindu nahi nuke halako egunetan* — «Janela bat»

**Kategoria:** lokuzioa · **Antzekoak:** *negar lehortu*, *bihotza arindu*, *kontsolatu* · **Oharra:** *min* = oinazea, atsekabea; *min eman* = kalte/atsekabea egin; *min hartu* = mindu.
