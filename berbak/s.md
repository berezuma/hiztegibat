# SAILKATU #

Multzoka edo sailka banatu; sailkapen baten arabera ordenatu.

- *isiltasunak ere sailka daitezke* — «Kolore bat»
- *otoitzak ere sailka daitezke / esne-hortzeriak sailka daitezke* — «Kolore bat»

**Kategoria:** aditza · **Sinonimoak:** multzokatu, banandu, ordenatu · **Osaera:** *sail* (atal, kategoria) + *-katu*. Letretako *sailka daitezke* = sailkatu daitezke (laburtua, aldaera dialektala).

# SAKABANATU #

Toki batetik atera eta zabaldu, alde guztietara barreiatu.

- *ta agian noizbait eman asmoz gordetako / muxu guztiak lurretik sakabanatu ziren* — «Iritsi»

**Kategoria:** aditza · **Sinonimoak:** barreiatu, hedatu, banatu · **Antonimoak:** bildu, batu · **Osaera:** *saka-bana* (banaka-banaka) + *-tu*.

# SALNEURRI #

Zerbait saltzen den prezioa, salgaiari ezartzen zaion balio-zenbatekoa.

- *merke salneurria: zure bizitza* — «Zirkua»

**Kategoria:** izena · **Sinonimoak:** prezio · **Osaera:** *sal(du)* + *neurri* → "saltzeko neurria, baloratzeko maila".

# SAMIN #

1. (izenondoa) Garratza, gozoaren kontrakoa (zaporea); (hed.) bizipen mingarria.
2. (izena) Mina, atsekabe sakon eta luzaroa.

- *bete gaituzte dena gezurrez, / saminez* — «500 urte ta gero»

**Kategoria:** izenondoa/izena · **Sinonimoak:** garratz (1); atsekabe, oinaze (2) · **Antonimoak:** gozo · **Erregistroa:** jasoa.

# SARE #

1. Hari edo soka korapilatuz egindako ehuna (arrantzakoa, kirolekoa…).
2. Interneta, sarea; konexioz lotutako multzoa.

- *gure aita sarean eskelak leitzen dabil* — «Etxe bat»

**Kategoria:** izena · **Sinonimoak:** Internet, web (2) · **Esamoldeak:** *sarea bota* (arrantzan), *sare sozial*, *sarean ibili*.

# SALBUESPEN #

Arau orokor batetik kanpora geratzen den kasua; arautik kanpoko egoera berezia.

- *larrituta nago eta bai, salbuespena naiz / zerbait alda dezakedala sinesteko lain* — «Dortoken mendean»

**Kategoria:** izena · **Sinonimoak:** salbuera, kanporaketa, eskualpenak · **Osaera:** *salbu* (arautik kanpo, libre) + *-espen* (izen-atzizki abstraktua, ahapeldi-modukoa).

# SARRAILA #

Ateak edo kutxak giltzaz ixteko mekanismoa; itxitura-tresna.

- *sarraila lehertzekotan / ene infernuko atea / zabalikan izango duzu* — «Ordaina»

**Kategoria:** izena · **Sinonimoak:** itxidura, giltzarrapo (zehazkiago candado), morroilo · **Erregistroa:** mailegua (gaztelaniazko *cerraja*-tik; baita *zerraila* aldaera).

# SEINALATU #

Behatzaz edo seinalez nabarmendu, agerian utzi; (hed.) salatu, izen-emanik utzi.

- *Behinola sunormalak etorri ziren / Manifestatzera / Onak eta txarrak seinalatuz / Ongizatearen izenean* — «Onak eta txarrak»

**Kategoria:** aditza · **Sinonimoak:** nabarmendu, salatu, atzamarrez markatu · **Erregistroa:** mailegua (gaztelaniatik *señalar*); ahozko hizkeran ohikoa.

# SINESMEN #

Egiatzat hartzen den ustea; fedea, konbentzimendua.

- *eta sinesmen horretan / ardazten da gure mundua* — «Teoria bat»

**Kategoria:** izena · **Sinonimoak:** uste, fede, konbikzio · **Osaera:** *sinetsi* (sinistu) + *-men* · **Lotutakoak:** *sinesgarri*, *sineskeria*.

# SEGATU #

Belarra, garia edo bestelako landareak segaz edo makinaz moztu; (hed.) zerbait suntsitu edo mozteko mugimendu zabal batez kendu.

- *zure galsoro guztiak segatu gure ogitik jateko* — «Sutxakurrak»

**Kategoria:** aditza · **Sinonimoak:** ebaki, moztu, eraitsi · **Lotutakoak:** *sega* = belar-mozteko tresna; *segapoto* = belar-mozteko makina.

# SENDAGAI #

Gaixotasun bat sendatzeko erabiltzen den substantzia; botika.

- *zein da gai infrasoinuak entzuteko / behingoz aintzat hartzeko / sendagai ala birus aukeratzeko* — «Infrasoinuak»

**Kategoria:** izena · **Sinonimoak:** botika, medikamentu · **Osaera:** *sendatu* (osatu, sendoarazi) + *gai* (erabilgarria, materiala) → "sendatzeko gaia".

# SENITARTEKO #

Familiakoa, etxekoa; senide den pertsona.

- *agur ahizpak eta senitarteko guztiak / agur lagunak eta jolasten ginen tokia* — «Maravillas»

**Kategoria:** izena · **Sinonimoak:** familiakoa, senide, etxekoa · **Osaera:** *senide* (familiakoa) + *arte* (artean) + *-ko* → "senideen artean dagoena".

# SETIATU #

Hiri edo gotorleku bat indarrez inguratu, kanpotik ezin sartu eta barrutik ezin atera utzi.

- *geroak zaituztela setiatuko / xake-mate kultural batez* — «Xake-mate kultural bat»

**Kategoria:** aditza · **Sinonimoak:** inguratu (gerla-zentzuan), bahitu (lekuari), tinkatu · **Lotutakoak:** *setio* = inguraketa, asedio · **Erregistroa:** jasoa.

# SINISKERIA #

Funts-froga gabeko sinesmenetan oinarritutako jokabidea; superstizioa.

- *komunikabideen komun-zuloetatik / ezjakintasun eta siniskeriaren itsasora* — «Izebergaren punta»

**Kategoria:** izena · **Sinonimoak:** sineskeria, superstizio · **Osaera:** *sinis(tu)* (sinetsi) + *-keria* (jokabide gaitzesgarriaren atzizkia: *gezurkeria, zekenkeria*).

# SOMATU #

Hauteman, sentitu, antzeman; argi ikusi gabe iritzi edo igarri.

- *zerbait somatuko zuen beharbada* — «Etxe bat»

**Kategoria:** aditza · **Sinonimoak:** antzeman, igarri, hauteman, sumatu (aldaera) · **Erregistroa:** ahozkoa eta idatzizkoa; *sumatu* da forma estandarra.

# SUGAR #

Suaren mihia, garra; sutearen argi-mugimendua. (Hed.) grina bizia.

- *sugar hau guztiz inoiz itzal ez dadin* — «Etxe bat»

**Kategoria:** izena · **Sinonimoak:** gar, su-mihi, lar (aldaera zaharra) · **Osaera:** *su* + *gar* (garra) · **Antonimoak (hed.):** hoztasun.

# SUKALDARI #

Sukaldean janaria prestatzen duen pertsona; jakigilea.

- *gauzak gordin daude hemen / sukaldarien herrian* — «Hemen sukaldarien herrian»

**Kategoria:** izena · **Sinonimoak:** jaki-egile · **Osaera:** *sukalde* (sua + alde) + *-ari* (lanbide-atzizkia: *baserritari, mendizari* gisara) → sukaldean dabilena.

# SUTE #

Su handia eta kaltegarria, kontrolik gabe hedatzen dena; (hed.) gatazka edo nahaste handia.

- *nonbaiten sute erraldoiren bat / itzali beharko balitz bezala* — «Sute bat»
- *sute historiko bat, larrialdi irteera* — «Bigarren eskuko amets»

**Kategoria:** izena · **Sinonimoak:** su-galda, su-kalte, garra · **Osaera:** *su* + *-te* (gertaera, multzoa adierazten duen atzizkia: *eurite, elurte, gosete*).

# SUTXAKUR #

Suzko jolas-tresna (pirotekniako kohete txiki edo zaratatsua); (hed.) bat-bateko distira-eragile, baina iraupen gutxikoa eta engainagarria.

- Abesti baten izenburua: «Sutxakurrak» — *Denbora da poligrafo bakarra* (2014)
- *sutxakurrak bezala / argia gezur* — «Sutxakurrak»

**Kategoria:** izena · **Osaera:** *su* + *txakur* → "suzko txakurra"; tradiziozko piroteknian, lurrean txakurraren modura korrika eta zaratan ibiltzen den koheteari deitzen zaio · **Sinonimoak:** kohete, su-festa-piezatxo.
