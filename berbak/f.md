# FABORE #

1. Norbaiti egiten zaion mesedea, laguntza ematea.
2. (Iparraldean, dialektoetan.) *Alde* zentzuan: *fabore izan* = alde egon, defendatu.

- Abesti baten izenburuan: «Emazten fabore II» — *Libre ©* (2003)

**Kategoria:** izena/lokuzio · **Sinonimoak:** mesede, lagungarri, alde · **Erregistroa:** mailegua (gaztelaniatik *favor*, Erdi Aroan euskaratua); Iparraldean eta literatur euskaran bizia, *alde* zentzuko erabilera bereziki · **Lotutakoak:** *faboratu* = lagundu, alde egin · **Oharra:** abestiaren izenburua Etxepareren *Emazten fabore* (1545) lan klasikoari keinu zuzena.

# FOLKLORE #

Herri baten ohitura, ipuin, abesti, dantza eta sinesmenen multzoa; tradizio biziaren altxorra. (Hed., gaitzezkoz) bitxikeria gisa tratatua, ez serioki hartua.

- Abesti baten izenburua: «Folklore» — *Payola* (2009)
- *Hargatik agian aurreiritziak / zuretzat gaur eta beti / folklore baikara* — «Folklore»

**Kategoria:** izena · **Sinonimoak:** herri-jakintza, tradizio · **Erregistroa:** mailegua (ingelesetik, jatorrian *folk* "herria" + *lore* "jakintza") · **Oharra:** abestian gaitzezkoz darabil, hizkuntza-gutxiengoak sailkatzeko erabili ohi den ikuspegi murriztailearen kontra.

# FROGA #

Zerbait egiazkoa dela erakusten duen seinalea edo erakustaldia; ebidentzia.

- *Hortzak kendu nahi zenizkigun baina hala ere / bestela ikasi genuen kosk egiten / Zeinek behar du froga gehiago?* — «Folklore»

**Kategoria:** izena · **Sinonimoak:** ebidentzia, erakuspen · **Aditza:** *frogatu* = froga eman, egiaztatu · **Erregistroa:** mailegua (latinetik *proba*, gaztelaniatik *prueba* > euskaraz *froga*).

# FEREKA #

Eskua leunki pasatzea, laztana; maitekiro ukitzea.

- *txakurrak bere ferekak eskatzen dizkit* — «Etxe bat»

**Kategoria:** izena · **Sinonimoak:** laztan, balaku, ferekaldi · **Aditza:** *fereka egin / ferekatu* = laztandu.
