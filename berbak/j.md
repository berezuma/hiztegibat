# JABE #

Norbait edo zerbait beretzat duen pertsona; nagusi, ardura duena.

- *Ta txakur denek izan ohi dute / bere jabearen itxura* — «Irailak 10»

**Kategoria:** izena · **Sinonimoak:** nagusi, ugazaba · **Antonimoak:** mendeko, morroia · **Lotutakoak:** *jabetu* = bereganatu, konturatu; *jabetza* = norbaiten esku egotearen egoera.

# JABETU #

1. Zerbaiten jabe egin; norberarena bihurtu.
2. Konturatu, ohartu; ezagutza-mailara iritsi.

- *behingoz jabetu zaitezte / benetako egoeraz* — «Itxaropena agortzen»
- *eta amorrua berriz / jabetzen da nitaz* — «Lotsarik gabe»

**Kategoria:** aditza · **Sinonimoak:** jabego hartu (1); konturatu, ohartu (2) · **Osaera:** *jabe* (jabea, nagusia) + *-tu* · **Lotutakoak:** *jabetza* = jabe izatea.

# JAIO #

Munduratu, sortu; ama baten gandik kanporantz etorri (animaliak, gizakiak); zerbait sortu edo agertu hasi.

- Diskoaren eta abesti baten izenburua: «Jaio.Musika.Hil» — *Jaio.Musika.Hil* (2005)
- *honetarako jaio nintzen / ta honengatik hilko naiz* — «Jaio.Musika.Hil»

**Kategoria:** aditza · **Sinonimoak:** sortu, munduratu · **Antonimoak:** hil · **Lotutakoak:** *jaiotza, jaiotegun, jaioterri*.

# JAKINMIN #

Zerbait jakiteko, ezagutzeko gogo bizia; mundua eta gertaerak ulertu nahia.

- *galdera dator nire burura / zer ote bestaldean / ezin ase jakinmina / jauzia eman arte* — «Non bestela»

**Kategoria:** izena · **Sinonimoak:** kuriositate, jakingura · **Osaera:** *jakin* + *min* (gogo bizia, beharra adierazteko atzizki-funtzioan: *etxe-min, herri-min, gose-min*) → "jakiteko mina, gogo handia".

# JANELA #

Leihoa. Euskarazko hitz arrunta *leiho* da; *janela* (gaztelaniaz/portugesez/galegoz *janela/ventana*) hemen baliabide poetiko gisa darabil, abestiaren izenburua bera dela.

- *janela ireki bat zugana / behar nauzunean naramana / barneranzko janela txiki bat* — «Janela bat»

**Kategoria:** izena · **Sinonimoak (euskara batuan):** leiho · **Oharra:** disko berean *leiho* hitza ere ageri da («Etxe bat»: *eman dizkit egunonak gure leihotik*); kontrastea nahita egina dirudi.

# JANTZI #

1. (aditza) Arropa soinean ipini.

- *ederrak dira kaleak / jendearen jantzitan* — «Teoria bat»

2. (izena) Arropa, soinekoa.

**Kategoria:** aditza/izena · **Sinonimoak:** beztitu, soinean hartu (1); arropa, soineko, beztimenda (2) · **Antonimoak:** erantzi, biluzi (1) · **Oharra:** letretako *jantzitan* = jantzietan (mugagabe/inesibo poetikoa).

# JAUNARTZE #

Kristau-fedean, lehen aldiz Eukaristia hartzeko ekitaldia, ohikoki 7-10 urte arteko haurrek egiten dutena; (hed.) gizarte- eta familia-errituzko ekitaldia.

- *lehenengo jaunartzea egin nuenetik / eskola atzean utzi nuen aspalditik* — «Nortasuna eraikitzen»

**Kategoria:** izena · **Sinonimoak:** komunio, lehen-jaunartze · **Osaera:** *jaun* (Jainkoa, eukaristiazko ostia) + *hartze* (hartzearen ekintza) → "Jauna hartzea".

# JAUSI #

Erori, beherantz joan ezustean. Mendebaldeko eta bizkaierako aldaera (cf. *erori* batuan).

- *orekak ez du balio lurrean zaudenean / orekak ez du balio aspaldi jausi zarenean* — «Oreka»

**Kategoria:** aditza · **Sinonimoak:** erori, bota, jausi · **Antonimoak:** zutik egon, igo · **Erregistroa:** mendebaldekoa eta ohikoa Berri Txarraken letretan (Lekunberri-Iparraldea baino areago).

# JELOSKOR #

Bekaitzez betea, beste batek duenagatik kezkatua; norbaitenganako maitasunean parteliariarekin lehiatzen dena.

- *gela txikiegi, ohea handiegi / kanpoan mundua jeloskor nire zai* — «Kanta goibelak»

**Kategoria:** izenondoa · **Sinonimoak:** bekaiztsu, ondokori, inbidiatsu · **Erregistroa:** mailegua (gaztelaniatik *celoso*, frantsesetik *jaloux*) · **Osaera:** *jelos* (mailegua) + *-kor* (joera adierazten duen euskal atzizkia) → "jelos egoteko joera duena".

# JENDARTE #

Gizartea, jendearen artekoa; pertsonen multzoa eta haien arteko harremanen sarea.

- *ez zara jendartean bizi eta / zertan ari zara / gogoratu nahi ez ditugunen / uzkia miazkatzen?* — «Stereo»

**Kategoria:** izena · **Sinonimoak:** gizarte, herri-saila · **Osaera:** *jende* + *arte* → "jendearen artean dagoena".

# JARDUN #

Zerbaitetan ari izan; lanean, hizketan edo eginkizun batean ibili.

- *(ik. dihardu, d.md): nirekin dihardu, nirekin dihardu* — «Besterik ez»

**Kategoria:** aditza · **Sinonimoak:** ari izan, aritu, ibili · **Oharra:** forma trinkoak ohikoak: *nihardun, hihardun, zihardun…*; izen gisa ere bai: *jardun luzea*.
