# IBAIERTZ #

Ibaiaren bazterra, ura eta lehorra elkartzen diren lerroa.

- *ibaiertzean utzi ditut / ezpata eta ezkutua* — «Lilura bat»

**Kategoria:** izena · **Sinonimoak:** ibai-bazter, errekaldi · **Osaera:** *ibai* + *ertz* (bazterra).

# IBILARAZI #

Norbait edo zerbait ibiltzera behartu, eragin; ibilian jarri.

- *oinutsik ta kristal gainean / ibilarazi bazaituzte* — «Alegia»

**Kategoria:** aditza (eragilea/kausatiboa) · **Osaera:** *ibili* + *-arazi* (eragiketa-atzizkia: *jakinarazi, eraman/eramaarazi*) → "ibiltzera behartu" · **Sinonimoak:** ibiltzera behartu, eraman.

# IFRENTZU #

Gauza baten beste aldea, ikusten ez dena; (hed.) zerbaiten alde ezkutu edo kontrakoa.

- *gizonezko hegemoniko txurion jarreran / Troyako smartphonetan / makrozenbakien ifrentzuan* — «Infrasoinuak»

**Kategoria:** izena · **Sinonimoak:** atzealde, kontrako alde, errebersoa · **Antonimoak:** aurrealde, aitzin · **Erregistroa:** jasoa.

# IGOGAILU #

Eraikin batean pertsonak edo gauzak goragoko edo beheragoko solairura eramaten dituen aparatua; aszensorea.

- *maleta eskuetan / igogailuan gora egin behar* — «26 segundotan»

**Kategoria:** izena · **Sinonimoak:** aszensore · **Osaera:** *igo* (gora egin) + *-gailu* (tresna-atzizkia, *garbigailu, edalgailu*) → "igotzeko tresna".

# IHES EGIN #

Toki batetik alde egin, libratu; arriskutik edo norbaitengandik aldendu.

- *zuek baino lehenago ihes egin nuelako da* — «Besterik ez»

**Kategoria:** aditz-lokuzioa · **Sinonimoak:** alde egin, hanka egin, ospa egin · **Oharra:** *ihesi joan*, *ihes egin (-ri)*, *iheslari*.

# IHAURRI #

Sakabanatu, barreiatu, lurrean zabaldu; (hist./mil.) etsaiari erasoan oldartu eta lekuz aldarazi.

- *gorputzak gorpu bihurtu arte / indarkeria erabiliz / presoak hartu, ihaurri, / eta ihauliak itzuli* — «Tortura nonnahi»

**Kategoria:** aditza · **Sinonimoak:** sakabanatu, barreiatu, hedatu · **Erregistroa:** jasoa/zaharkitua.

# IHESALDI #

Ihes egitearen ekintza; talde bat edo norbait toki batetik korrika ateratzea.

- *mundu guztia korrika dabilela ere ikusten dut / ezin asma lasterketa den / iduri du ihesaldi kolektibo bat* — «Infrasoinuak»

**Kategoria:** izena · **Sinonimoak:** ihes-bide, hanka-egite · **Osaera:** *ihes* + *-aldi* (gertaera-atzizkia: *jaialdi, gerraldi*) → "ihes egiteko unea/ekintza".

# IKARA #

1. Beldur bizia, izua.
2. Dardara, astindua.

- *loratu dira ikara berriak* — «Lilura bat»
- *maite zaitut batek ikaratzen gaitu* — «Besterik ez» (ik. *ikaratu*)

**Kategoria:** izena · **Sinonimoak:** beldur, izu (1); dardara, dardar (2) · **Aditza:** *ikaratu* = beldurtu, dardaratu.

# IKUSMEN #

Ikusteko ahalmena; begien zentzumena.

- *ikusmenak itsututa gaude* — «Tren bat»

**Kategoria:** izena · **Sinonimoak:** ikuste, bista · **Osaera:** *ikus(i)* + *-men* (ahalmena: *entzumen, usaimen, dastamen, ukimen*).

# ILARGI #

Lurraren satelitea; gauez argi egiten duen gorputza.

- *ilargia da laru* — «Kolore bat»

**Kategoria:** izena · **Sinonimoak:** hilargi (aldaera) · **Osaera:** *(h)il* + *argi* ("hilen argia" edo "hilabetearen argia").

# ILOBA #

Anai-arreben semea edo alaba; baita biloba ere (seme-alaben umea), batez ere mendebaldean.

- *hogei arte zenbatzen ikasi du ilobak* — «Etxe bat»

**Kategoria:** izena · **Oharra:** testuinguruaren arabera 'sobrino/a' edo 'nieto/a'; bereizteko *biloba* erabil daiteke bigarrenerako.

# ILDO #

1. Goldeak edo lanabesak lurrean uzten duen ebakidura zuzena, hazia ereiteko egiten dena.
2. (Hed.) Bide markatua, jarraibidea; jarrera edo joera bat.

- *historiak ahaztuko dituenetan / narrastiak beti ildorik sakonena* — «Hozkia»

**Kategoria:** izena · **Sinonimoak:** ubide (irudi.), bide, marra (1); jarraibide (2) · **Esamoldeak:** *ildo beretik segi* = bide berari jarraitu.

# ILTZATU #

Iltze batez josi, finkatu; (hed.) gelditu, mugitu ezin den moduan ipini.

- *Izen-abizenak jarri nituen oroitzapenetan / bi begi iltzatu ohartu gabe jada ez nintzen horretan* — «Hasi eta bukatu»

**Kategoria:** aditza · **Sinonimoak:** josi, finkatu, geldiarazi · **Osaera:** *iltze* (untza) + *-tu* · **Esamoldeak:** *begiak iltzatu* = begirada ez askatu.

# INAUSI #

Landareei adar lehor edo soberako batzuk moztu, hazi eta sasoi onean egon daitezen; (hed.) zerbait ebaki edo mugatu, indarrez.

- *behin eta berriz inausi digute hitza / debekuaren artaziekin* — «Izena, izana, ezina»

**Kategoria:** aditza · **Sinonimoak:** moztu, kimatu, ebaki · **Erregistroa:** jasoa/literarioa; baratzaintzaren hiztegitik datorrena.

# INDARKERIA #

Indar fisikoa edo morala bortizki erabiltzea, kalte egiteko asmoz.

- *gorputzak gorpu bihurtu arte / indarkeria erabiliz / presoak hartu, ihaurri* — «Tortura nonnahi»
- *indarkeria behin ta berriz / jipoi guztiak estaliz* — «500 urte ta gero»

**Kategoria:** izena · **Sinonimoak:** biolentzia, bortizkeria · **Antonimoak:** baketasun, leuntasun · **Osaera:** *indar* + *-keria* (gehiegikeria edo jokabide gaitzesgarria adierazten duen atzizkia) → "indarraren gaiztotasunezko erabilera".

# INFRASOINU #

Giza belarriak entzun ezin duen baxuegiko maiztasuneko soinua (20 Hz baino baxuagokoa); (hed.) sumatzen ez dugun arren badagoen indar edo mehatxua.

- Abesti eta diskoaren izenburua: «Infrasoinuak» — *Infrasoinuak* (2019)
- *badatoz infrasoinuak, somatzen ez ditugunak / itsasoan zehar, lanerako baldintza eskas eta makur / horietan edota eskoletan bide eginaz* — «Infrasoinuak»

**Kategoria:** izena · **Osaera:** *infra-* (latinetik, "azpian, baxuagoan") + *soinu* (hots, hotsa); hibrido jasoa euskal hitzarekin · **Antonimoak:** ultrasoinu.

# IPARRA GALDU #

Norabidea galdu, nora jo ez jakin; (hed.) zentzua edo helburua galdu.

- Abesti baten izenburuan: «Iparra galdu: Hegora joan» — *Jaio.Musika.Hil* (2005)

**Kategoria:** esamoldea · **Osaera:** *ipar* (iparraldea, norabide-erreferentzia) + *galdu* · **Antonimoa:** *iparra hartu* = norabidea aurkitu · **Antzekoak:** norabidea galdu, zorabiatu.

# IRUDIMEN #

Buruan irudiak edo egoerak asmatzeko ahalmena; sormena.

- *irudimen tona baten beharra daukat / edozeri iraultza deitzen jarraitzekotan* — «Dortoken mendean»

**Kategoria:** izena · **Sinonimoak:** sormen, fantasia, imajinazio · **Osaera:** *irudi* (buruko irudia) + *-men* (ahalmena adierazten duen atzizkia: *jakimen, hitzemen*).

# IRAULTZA #

Botere edo egoera baten errotiko aldaketa, sarri indarrez; aldaketa sakona.

- Abesti baten izenburuan: «Iraultza txikien asanblada» — *Jaio.Musika.Hil* (2005)

**Kategoria:** izena · **Osaera:** *irauli* (azpikoz gora jarri) + *-tza* · **Lotutakoak:** *iraultzaile* = iraultzaren aldekoa · **Sinonimoak:** matxinada (errebolta), erreboluzio.

# IRAZEKI #

Su eman, piztu, sutan jarri.

- *nonbaiten sute erraldoiren bat irazeki / izan balitz bezala da* — «Sute bat»

**Kategoria:** aditza · **Sinonimoak:** piztu, su eman, sutu · **Erregistroa:** jasoa/zaharkitua · **Antonimoak:** itzali.

# IRETSI #

Janaria edo edaria zintzurretik behera bota; (hed.) zerbait osorik kontsumitu edo onartu, kritikatu gabe.

- *Nire alde sei soka besterik ez: / galdetzeko haina kemen / Gure kontra dena irensten duen inertzia geza* — «Dortoken mendean»

**Kategoria:** aditza · **Sinonimoak:** irentsi (aldaera), trago egin, hustu · **Esamoldeak:** *iretsi gaitza* = onartu gaitza, "ezin iretsi".

# IRRI #

Aurpegian irudikatzen den poz-keinua, irribarrea; barre arina.

- *Zaldi Eroaren tirak atera dit / eguneko lehen irria* — «Etxe bat»

**Kategoria:** izena · **Sinonimoak:** irribarre, barre · **Esamoldeak:** *irri egin*, *irriz lehertu*, *irrigarri*.

# IRTENBIDE #

Egoera zail batetik ateratzeko bidea; konponbidea.

- *irtenbide bat bada / izan daiteke hemen* — «Teoria bat»

**Kategoria:** izena · **Sinonimoak:** konponbide, atera-bide, soluzio · **Osaera:** *irten* (atera) + *-bide*.

# ISILTASUN #

Isilik egotea; hotsik eza, baretasuna.

- *isiltasunaren bagoian / idazten / tren batean nago* — «Tren bat»

**Kategoria:** izena · **Antonimoak:** zarata, hotsa, oihu · **Osaera:** *isil* + *-tasun*.

# ISLATU #

Argia, irudia edo soinua azalera batean itzularazi; (hed.) zerbait erakutsi edo adierazi.

- *ezereza mila moduz islatzen da, entzun* — «Kolore bat»

**Kategoria:** aditza · **Sinonimoak:** errainu egin, itzuli (argia), adierazi (hed.) · **Lotutakoak:** *ispilu*, *isla*.

# ITSULAPIKO #

Diru-eraztun txikiak gordetzeko ontzi itxia, lapur-itxurako pertsonai edo txerritxoa irudikatzen duena; (hed.) gordetako ondasunen iturria.

- *itsulapikoa hustu zutenek bahitu medioetan / larri dabiltzanei behar dutena esanez: / horra errudunak!* — «Zuri»

**Kategoria:** izena · **Osaera:** *itsu* (itsua, ikusten ez duena — *itsu-itsuan* gordeta) + *lapiko* (eltzea) → "itsuko eltzea, ezin ikusi den ontzia" · **Sinonimoak:** alkantzia, txerritxo.

# ITOMEN #

Itotzearen ekintza edo egoera; arnasarik ezin hartu izana, fisikoki edo sentimenduki.

- *behingoz jabetu zaitezte / benetako egoeraz / berezko kultura duen / herri baten itomena* — «Itxaropena agortzen»

**Kategoria:** izena · **Sinonimoak:** itzalmen, itoaldi, asfixia · **Osaera:** *ito* (arnasa galarazi) + *-men* (ahalmena edo ekintza-egoera adierazten duen atzizkia).

# ITSATSI #

Bi gauza elkarri lotu kola, kola-paper edo presio bidez; (hed.) zerbaiti tinko atxiki edo kateatu.

- *beroki heze baten antzera / azalera temati itsasten* — «Bigarren itzala»
- *distortsioari itsatsita / barneko galderei entzungor egiteko* — «Poligrafo bakarra»

**Kategoria:** aditza · **Sinonimoak:** atxiki, lotu, kolatu · **Antonimoak:** askatu, bereizi · **Lotutakoak:** *itsaskor* = itsasten dena.

# ITSUAREN ESKUAREN PAREKO #

Norbait edo zerbait ezinbestekoa, beti laguntzeko prest dagoena —itsu batek bere eskuaz duen mendekotasun eta konfiantza adierazten du.

- *itsuaren eskuaren pareko izan* — «Maitasun bat»

**Kategoria:** esamoldea · **Antzekoak:** *bigarren begia izan*, *makulu izan* · **Oharra:** *pareko* = bezalakoa, parekidea (ik. *pareko*, p.md).

# ITXURALDATU #

Itxura aldatu, beste forma batera bihurtu; (hed.) jatorrizko esanahia edo izaera aldatuz erabili.

- *ta hitz asko ikusi dut zentzua galtzen / ta hitz asko ikusi dut itxuraldatzen* — «Achtung!!»

**Kategoria:** aditza · **Sinonimoak:** desitxuratu, eraldatu, mozorrotu · **Osaera:** *itxura* (kanpoko forma) + *aldatu* → "itxuraz aldatu".

# ITZAL #

1. Argia gorputz batek galarazten duen iluna; gerizpea, freskura.
2. (Hed.) Norbaitek duen begirune-indarra, prestigioa, eragina.

- Abesti baten izenburuan: «Bigarren itzala» — *Denbora da poligrafo bakarra* (2014)

**Kategoria:** izena · **Sinonimoak:** gerizpe, itzalpe (1); ospe, eragin, begirune (2) · **Lotutakoak:** *itzali* (aditza), *itzaltsu* = itzal handikoa.

# ITZEL #

1. Ikaragarri handia edo sendoa, harrigarria.
2. (adb.) Oso ondo, ezin hobeto.

- *itzel / bi igel ergel* — «Alegia» (esklamazio gisa)

**Kategoria:** izenondoa/adberbioa · **Sinonimoak:** ikaragarri, izugarri, eskerga, sekulako · **Erregistroa:** ahozkoa eta indartsua; literaturan ere bai.

# ITZALI #

1. Sua, argia edo aparatua amatatu.

- *eguzkiak itzali ditu gainerako argiak* — «Janela bat»
- *sugar hau guztiz inoiz itzal ez dadin* — «Etxe bat»

2. Soinua, oroitzapena edo bizia desagertu, ahuldu.

**Kategoria:** aditza · **Sinonimoak:** amatatu, itzaldu · **Antonimoak:** piztu, irazeki.

# IZURRI #

Gaixotasun kutsakor handia, jende askorengana azkar zabaltzen dena; (hed.) zabaltzen den okerra edo ohitura kaltegarria.

- *hala zabaltzen da izurri berri hau: irribarre batez / kanpokoa mespretxatzen aurrerakoi trajea kendu gabe* — «Zuri»
- *isolamendua izango da boladan jarriko duten / izurritea eta hori bera estaltzen asmatzea* — «Spoiler!»

**Kategoria:** izena · **Sinonimoak:** epidemia, pandemia, oinaze-zaparrada · **Lotutakoak:** *izurrite* = izurri-aldia; *izurritu* = izurriz kutsatu · **Erregistroa:** jasoa.

# IZKRIBU #

Idatzia, eskuz idatzitako testua; bereziki, eskuizkribu zaharra edo paretetan etab. utzitako idazkia. Hitz jasoa.

- *jakin nahi nuke nork betetzen duen orain / nik utzitako zelda / ea entelegatzen duen hormako izkribu tipia: / "eroria burrukara"* — «Aspaldian utzitako zelda»

**Kategoria:** izena · **Sinonimoak:** idazkun, eskuizkribu · **Erregistroa:** jasoa/literarioa (latin/erromantzeko *scribere*-tik).

# IZOZMENDI #

Itsasoan flotatzen duen izotz-masa erraldoia; iceberg-a.

- *izozmendi bat bularrean / Titanic-en orkestra hartan* — «Besterik ez»

**Kategoria:** izena · **Osaera:** *izotz* (hielo) + *mendi* → "izotzezko mendia". (Hed.) bihotz hoztua, sentimendu izoztua.
