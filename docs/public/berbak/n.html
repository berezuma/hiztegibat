Hiztegi bat

Gorka Urbizuk idatzitako letren hiztegia, euskara ikasteko.

399 hitz · 1997–2026

Alfabetoa · Hutsunea bete jokoa · Diskoak eta abestiak

N

NINI

1. Begiaren erdiko zulo beltza, argia barruratzen den tokia.

2. Haur txikia, sehaska-haurra.

  • hegalak zabal-zabal / bi orratz-buru ninietan — «Bele erraldoia»

Kategoria: izena · Sinonimoak: begi-nini (1); haurtxo, ume (2) · Esamoldeak: begien ninia bezala zaindu = oso maitatua zaindu.

NARRASTI

Lurrean sabelez narras dabilen animalia: sugea, dortoka, muskerra…; (hed.) jokabide makur eta isilekoa duen pertsona.

  • historiak ahaztuko dituenetan / narrastiak beti ildorik sakonena — «Hozkia»

Kategoria: izena · Sinonimoak: narras-animalia · Osaera: narras (lurrean herrestaka) + -ti (joera-atzizkia) → "narras dabilena".

NEKAEZIN

Inoiz nekatzen ez dena, etengabe ari dena.

  • nire datuak aspaldian dauzka / zorionaren lobby nekaezinak — «Zorionaren lobbya»

Kategoria: izenondoa · Sinonimoak: nekagaitz, indartsu, bizkor · Antonimoak: neke-erraza · Osaera: neke (akidura) + ezin (ezintasuna) → "nekatzen ezin dena", negarrezin, hilezin gisara.

NONNAHI

Edonon, leku guztietan; non nahi den.

  • Abesti baten izenburuan: «Tortura nonnahi» — Berri Txarrak (t/g) (1997)

Kategoria: adberbioa · Osaera: non + nahi → "non nahi den" · Aldaerak: nonahi, edonon · Antonimoa: inon ez.

NORAEZEAN

Norantz jo ez dakiela; norabide finkorik gabe ibili.

  • bakardadean / haurtzarorik ezean / kale gorrian / hotzak, noraezean — «Haurtzaroa lapurtu zidaten»

Kategoria: adberbioa · Sinonimoak: noraezean ibili = ipar gabe ibili (cf. iparra galdu, i.md) · Osaera: nora (galde-hitza) + ez + -ean (inesibo poetikoa) → "nora doan ez dakiela".

NORTASUN

Norbaiten izaera berezia, besteengandik bereizten duena; norberaren identitatea.

  • Abesti baten izenburuan: «Nortasuna eraikitzen» — Berri Txarrak (t/g) (1997)

Kategoria: izena · Osaera: nor (galdetzailea) + -tasun (abstraktua) · Lotutakoak: nortasun-agiri = NAN; nortasun handiko = izaera sendokoa · Sinonimoak: izaera, identitate, izate.
